# US County Collector Tracking Sheet

_Generated 2026-08-29 from Census `national_county2020.txt` (50 states + DC)._

## Purpose

Single checklist for **every US county-equivalent** so Umbra can grow identity/public-records
coverage deliberately — not ad-hoc URL dumps. This is the **entity-graph coverage map**
for person / land / corp / SOR.

## How coverage works (plan)

| Layer | What “done” means | Who owns it |
|-------|-------------------|-------------|
| **L0 Federal** | NSOPW, EDGAR, CourtListener, FEC, national obits | always on |
| **L1 State** | SOS business + courts + sex-offender homepage | `us_state_portals` → portals / SOR collectors |
| **L2 County deep** | Assessor + clerk/recorder + local courts allowlisted GET | `public_records_portals` pack + `county_records` |
| **L3 Facts in lake** | Queried HTML/JSON + source URL on graph | `people.sqlite` / RF lake |

**Rules:** name-token ≠ identity · first+last for SOR · no PACER/login/captcha · no Crawlee · store the link.

## Legend

- `[x]` / `[ ]` — checklist for operators / agents filling packs
- **State row:** SOS · Courts · SOR (L1)
- **County row:** Deep pack (L2). Open = inherits state+federal only until a pack ships
- FIPS = Census state+county code

## Rollup

- States + DC: **51**
- County-equivalents: **3143**
- L1 state packs (SOS+courts+SOR): **51/51**
- L2 county deep packs: **75/3143**

### Priority fill order

1. Keep L1 at 51/51.
2. Deep-pack **operator geos**: NWA (AR), SF Bay + SD (CA) — expand adjacent counties next.
3. Large metros when investigating there (Cook IL, Harris TX, Maricopa AZ, …).
4. Never claim nationwide parcel scrape — L2 is curated portals per county.

### Machine data

- `src/umbra/data/geo/us_county_collector_tracker.json` — full status (shipped)
- `src/umbra/data/geo/us_counties_by_state.json` — compact name+FIPS
- `src/umbra/data/geo/national_county2020.txt` — Census source
- Regenerate: `python scripts/generate_us_county_tracker.py`
